# Contributing to Awesome OG Images

Thank you for your interest in contributing!

## Guidelines

- **Search existing entries** before adding a new one to avoid duplicates.
- **Quality over quantity** - Only add tools you've actually used or can vouch for.
- **Use the format** - Follow the existing style:
  - `**[Name](URL)** - Short description.`
- **Keep descriptions concise** - One sentence is ideal.
- **Sort alphabetically** within each section.

## Adding a New Entry

1. Fork this repository
2. Add your entry in the appropriate section
3. Ensure the link works
4. Submit a pull request

## Reporting Issues

Found a broken link or outdated information? Open an issue with:
- The entry name
- What's wrong
- Suggested fix (if applicable)

## Code of Conduct

Be respectful and constructive. We're all here to help each other build better OG images.
